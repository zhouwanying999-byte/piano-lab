和弦与低音

调号、音阶与节奏

调号和主调。调号依次升 F、C、G、D，在各个八度都有效。E 大调也使用这组调号。这里听到的是以 C♯ 为主音的升 C 小调，开头的 C♯–E–G♯ 是它的主三和弦。

升 C 自然小调。C♯–D♯–E–F♯–G♯–A–B–C♯。这两小节没有临时升降号。和声小调会把 B 升为 B♯，本片段还没用到这个变化。指法中的数字只指手指。

拍子。带竖线的 C 是 2/2。每小节两大拍，每大拍有两组三连音。每组三音均分一个四分音符的时间。左手八度从小节开头持续到小节末。

音名和八度。中央 C 是 C4。右手 G♯3 在中央 C 下方，C♯4 与 E4 在中央 C 上方。左手的两个八度分别是 C♯2＋C♯3 与 B1＋B2。
